# Contributing

Thanks for helping improve `workflow-stoplight`.

## Development

1. Use Node.js 20 or newer.
2. Run `npm test` before opening a pull request.
3. Keep the router deterministic and dependency-free unless a change is discussed first.
4. Add or update a synthetic example and a test for behavior changes.
5. Do not include credentials, private customer data, local paths, or screenshots containing personal information.

## Pull requests

Explain the problem, the routing rule changed, and why the new behavior is safer or more useful. Avoid claims about token savings or production reliability unless reproducible evidence is included.
