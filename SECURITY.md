# Security policy

## Scope

This project is a local deterministic router. It does not connect to accounts, APIs, browsers, repositories, or production systems.

## Reporting a concern

Please open a private GitHub security advisory when the concern could expose a user, or open a public issue for a non-sensitive bug. Do not paste credentials, private task data, or personal information into an issue.

## Important limitation

The tool is not a security scanner. A routing result must not be treated as authorization to handle private data or make an irreversible change.
